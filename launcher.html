怎么用

  1. 在 game 文件夹里双击 启动器.bat —— 它会开好本地服务器，并自动打开这个页面。
  2. 点上面任意一个入口。不要直接双击 index.html： 那样地址栏是 file://，浏览器会拦下 ES 模块，页面是空白的。
  3. 素材编辑器要保存（写回源码）必须走服务器；页面上会明确提示当前能不能存。
  4. 结束：关掉那个黑色命令行窗口即可（它就是服务器）。

快捷键：1 进游戏　2 进编辑器　R 重新检测

完整说明（含各项自检命令）在 README.md ——「编辑器存不上」先跑 node tools/check-server.mjs， 「页面打不开」先跑 node tools/check-boot.mjs。

打不开的话

浏览器说"无法访问" → 服务器没在跑：重新双击 启动器.bat。
页面空白 → 多半是用 file:// 直接打开了 html：请从这个启动器进。
编辑器保存报"没有 /__edit 接口" → 正在跑的是旧版服务器：关掉黑窗口重新启动。

端口不是死记的 5173：5173 被占用时服务器会自动顺延， 以服务器窗口打印的地址为准（这个页面会自动跟着实际端口走）。
